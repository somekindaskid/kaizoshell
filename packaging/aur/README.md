Packaging template, not an AUR listing. Publish the tagged source archive, select a project licence, update the PKGBUILD licence field and actual SHA-256 (`updpkgsums`), run `makepkg -si` on Arch, and generate `.SRCINFO` with `makepkg --printsrcinfo`. The package installs the CLI; `kaizo install --yes` initializes per-user QML/configuration. Do not mix the package-manager CLI and the online updater: use pacman/AUR to update the package, then run `/usr/bin/kaizo install --yes` and restart. The package does not modify user configuration in post-install scripts.
